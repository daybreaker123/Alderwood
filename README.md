# Alderwood

Marketing site for Alderwood, an AI consulting and implementation practice for mid-size companies.

## Preview

From this folder:

```bash
python -m http.server 4173
```

Then open http://localhost:4173

## Contact address

The footer address is the one the form uses. Replace `hello@alderwood.com` in `index.html` before publishing. The form opens a draft in the visitor’s email app. It does not store submissions.
